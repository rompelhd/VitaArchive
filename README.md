# VitaArchive

VitaArchive is a web application for browsing and downloading PlayStation Vita homebrew applications, games, ports, and utilities.

The website provides a simple interface for exploring the NeoVitaDB catalog and downloading community-developed software for the PlayStation Vita.

## Features

* Browse PlayStation Vita homebrew.
* Search applications by name.
* Filter by category:

  * Utilities
  * Ports
  * Games
* Responsive design for desktop and mobile devices.
* Fast and lightweight interface.

## Disclaimer

VitaArchive is an unofficial community project. It does not host or distribute copyrighted PlayStation software. The website is intended to provide access to publicly available homebrew applications created by independent developers.
